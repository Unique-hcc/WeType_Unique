# WeType_Unique

**微信输入法美化增强模块 · 背景材质、按键效果、品牌配色、Logo、剪贴板一次补齐**

## 功能特性

设置按「界面美化 / 按键效果 / 品牌色与字体 / 外观与 Logo / 底栏与快捷栏 / 剪贴板增强 / 配置与更新」组织。所有配置即时写入，重启微信输入法进程后生效；模块只在运行时修改，不替换、不改动输入法安装包。

| 分组       | 包含能力                                                      |
| :------- | :-------------------------------------------------------- |
| 界面美化     | 背景颜色 / 不透明度 / 圆角 / 模糊 / 边缘高光、Monet 动态配色、HyperOS 材质、系统液态玻璃 |
| 按键效果     | 按键反馈（弹簧 / 柔性形变）、按键高光（默认 / 玻璃彩光）                           |
| 按键震动     | 按下 / 抬起震动、系统预设与自定义手感、时长与强度调节                                   |
| 品牌色与字体   | 品牌色直染、功能键配色、候选跟随品牌色、壁纸取色色卡、系统 / 内置 / 自定义字体、功能键文本替换        |
| 外观与 Logo | 键盘 Logo（SVG / 图片，隐藏底圈）、隐藏键盘提示、豆包按键音、底栏适配                  |
| 底栏与快捷栏   | 液态玻璃底栏细调、自定义底栏按钮与排序                                       |
| 剪贴板增强    | 剪贴板搜索、品牌色对比自适应、跨设备剪贴板、去除时长 / 长度限制、卡片透明度                   |
| 配置与更新    | 配置导入导出、检查更新、模块激活自检、日志导出、禁用热更新                             |

### 界面美化

- 浅色与深色模式各自保存一套配色，编辑时实时预览渲染效果
- 窗口背景颜色、不透明度、模糊强度、圆角半径自由调节
- 边缘高光（edge highlight）开关与强度
- 跟随壁纸的 **Monet 动态配色**（Material You）：从当前壁纸主色用 HCT 算法派生整套界面 / 功能键色板
- **HyperOS 4 高级键盘材质** 与 **系统液态玻璃（Liquid Glass）** 支持
- 工具栏图标背景不透明度

### 按键效果

- **按键反馈**：柔性形变（向触点倾斜）两种风格，可调强度、时长、倾角
- **按键高光（Key highlight）**：沿按键轮廓描边的边缘光，跟随圆角与按键反馈
  - 默认风格：单色描边
  - **玻璃彩光（Iridescent）**：沿轮廓色相渐变，呈现玻璃折射虹彩；可分别调节顶 / 右 / 底 / 左四个锚点颜色与色相基准

### 按键震动

- 接入键盘根视图触摸事件，在按下 / 抬起时触发震动（hook：`wetype.key-vibration`）
- **按下震动 / 抬起震动** 分别可设，模式支持：**无震动 / 系统预设 / 简单自定义**
- 系统预设提供多档**预设手感**（PRESET_NAMES），自定义模式可调**震动时长**（10~200ms）与**震动强度**（1~255）
- 建议关闭输入法自带的按键震动，避免双重反馈；部分系统上「简单自定义」效果偏弱，推荐使用系统预设

### 品牌色与字体

- 品牌色直染、功能键配色（默认 / 原生灰 / 主题色）、候选词跟随品牌色
- **壁纸取色色卡**：设置页内置「壁纸 Monet 色卡」——从当前壁纸主色用 HCT 算法实时派生一整排圆角色卡（品牌强调色 + 多张壁纸派生色），点卡即选，无需手动输入色值；换壁纸随之刷新
- **功能键「主题色」色源**：可在「品牌强调色」与「壁纸取色」间切换；选壁纸取色时从色卡条点选任一壁纸派生色作为功能键面着色
- **锁定透明度**：勾选后从色卡 / 取色盘选色只改变色相、保留已调好的透明度；不勾则选色同时把透明度提到最高
- 字体：系统字体 / 内置字体 / 自定义字体文件
- 标点偏移（整体与逐字微调）、功能键文本替换（符号或 SVG 矢量图标）、123 键文本化、自定义符号尺寸

### 外观与 Logo

- **键盘 Logo**：内置 / 内置备选 / 自定义；支持 **SVG PathData** 或 **导入图片**
- 图片 Logo 可 **隐藏底圈（Hide base circle）**，图标颜色可跟随主题
- 隐藏键盘提示、豆包风格按键音
- 底栏适配（键盘背景与系统导航栏融合）

### 底栏与快捷栏

- **液态玻璃底栏**：模糊、折射、静置折射、触感反馈、底栏发光、壁纸取色等细调
- **自定义底栏**：开关输入法切换 / 键盘切换 / 剪贴板 / 常用语 / 语音 / 收起键盘按钮，并支持长按拖拽排序

### 剪贴板增强

- 剪贴板搜索、品牌色对比自适应
- 跨设备剪贴板可见化、去除存储时长限制、去除文本长度限制
- 粘贴后自动收起、打开时是、剪贴板 / 常用语卡片透明度调节

### 配置与更新

- 配置导出 / 导入（JSON），一键恢复默认
- **检查更新**：内置更新器，从发布仓库拉取版本清单并下载安装
- 模块激活状态自检、Xposed 日志导出
- 禁用微信输入法热更新（降低 Hook 因云端热修复失效的概率）
- 系统字体跟随

## 安装与使用

### 使用要求

- Android 12 及以上
- LSPosed 或兼容的 Xposed 框架，Xposed API 版本不低于 102
- 已安装并启用 **微信输入法（com.tencent.wetype）**

### 安装步骤

1. 安装模块 APK。
2. 在 LSPosed 中启用模块，**作用域勾选「微信输入法」**；保存后重启微信输入法进程让 Hook 加载。
3. 打开桌面入口进入设置；确认顶部显示「模块已激活」后可点击进入内置定制页。
4. 保存配置后按提示重启微信输入法进程，改动即可生效。

## 兼容性

- 模块依赖微信输入法的内部实现与资源名称，官方更新或云端热修复可能导致个别功能失效；开启「禁用热更新」可降低风险。
- 改名后的 `WeType_Unique`（`applicationId = com.hcc.wetypeunique`）与原 `WeType UI Enhanced`（`com.xposed.wetypehook`）**可并排安装**、在 LSPosed 中作为两条独立记录存在；但两者同时激活时会 hooks 同一输入法进程而叠加生效，建议同一时刻只激活其一。
- 设置数据写在宿主 `/data/data/com.tencent.wetype/shared_prefs/` 下的偏好文件中，不随模块重装丢失。

## 常见问题

<details>

<summary>保存后为什么没有立即生效？</summary>

配置在输入法进程启动时读取，保存后需点击设置页的「Restart WeType（重启微信输入法）」；在 LSPosed 里调整过作用域也一样，要重启微信输入法进程才会重新加载。

</details>

<details>

<summary>其他输入法能享受这些增强吗？</summary>

界面美化、按键效果、品牌色与字体、Logo 与字体替换、底栏与快捷栏、剪贴板增强等全部只针对微信输入法（com.tencent.wetype），不影响系统其它输入法。

</details>

<details>

<summary>某个功能突然失效了？</summary>

多半是微信输入法通过热修复改了内部实现，导致类名或资源名变化。可在设置中开启「Disable hot update（禁用热更新）」阻断其热修复，同时等待模块跟进适配。

</details>

<details>

<summary>需要 Root 吗？</summary>

模块本身由 LSPosed 加载，不要求 Root。设置页的「Restart WeType（重启微信输入法）」通过系统广播重启，通常免 Root；无 Root 时自动降级为打开微信输入法应用详情页手动停止。日志导出在收集输入法进程私有日志时会尝试 root 读取，无 root 时可能不完整。

</details>

<details>

<summary>检查更新拉不到新版本 / 装成了第二个 App？</summary>

由于本模块已更名为 WeType_Unique（`applicationId = com.hcc.wetypeunique`），若某分段指向的 APK 仍是旧包名编出的，安装时会装成「第二个 App」而非覆盖当前模块——属预期行为，可在 LSPosed 中停用旧模块。要确保覆盖更新，请保证该分段始终指向用 `com.hcc.wetypeunique` 编出的 APK。

</details>
